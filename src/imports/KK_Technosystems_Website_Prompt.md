# KK Technosystems — Complete Website Design & Frontend Development Prompt

Design and develop a **premium, modern, responsive corporate website for KK Technosystems**, an electronics, engineering and technology company.

The website must feel like a **high-end engineering and technology company**, combining industrial credibility, technical expertise and modern digital design.

The final result should look like a **professionally designed production website**, not a generic AI-generated template.

---

## 1. Brand Identity — Absolute Priority

The attached reference images contain the official KK Technosystems:

- Logo
- Brand colours
- Typography/font style
- Visual identity
- Design elements
- Brand details

Treat these images as the **absolute source of truth for the brand**.

### Do NOT

- Change the logo
- Redesign the logo
- Invent a different colour palette
- Introduce unrelated colours
- Change the font style unnecessarily
- Use a generic corporate font when the provided font is identifiable
- Make the website look like a different company

### Typography

Use the exact font from the supplied references wherever possible.

If the exact font is technically unavailable:

1. Identify the closest possible alternative.
2. Match its visual characteristics.
3. Preserve:
   - Weight
   - Letter spacing
   - Character proportions
   - Line height
   - Overall appearance

Typography must remain consistent across:

- Navigation
- Hero
- Headings
- Body
- Cards
- Buttons
- Forms
- Footer

### Colours

Extract the colour palette from the supplied KK Technosystems images.

Create a consistent design-token system for:

- Primary
- Secondary
- Background
- Surface
- Text
- Muted text
- Border
- Accent

**Do not invent a new colour palette.**

If a colour is not present in the brand references, use neutral tones only when necessary.
